🎮 Jeu d'action — Projet Unity

Jeu d'action inspiré de jeux comme Mega Bonk, développé avec Unity et C#.

Le joueur doit affronter des vagues d'ennemis, améliorer son personnage et survivre le plus longtemps possible.

🚧 Projet en cours de développement — certaines fonctionnalités sont encore en cours d'implémentation.

🕹️ Gameplay

Le jeu repose sur un gameplay de type survie / arena :

⚔️ Affrontement contre des vagues d'ennemis
👾 Ennemis avec différents comportements
📈 Progression du personnage
💥 Système de combat et de dégâts
🎯 Déplacement libre dans l'arène
🔄 Boucle de gameplay basée sur la survie et l'amélioration du personnage
